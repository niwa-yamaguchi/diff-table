# 1ファイル登録時のビュワーモード対応 設計書

- 日付: 2026-07-17
- 対象: `excel-diff.html`, `access-diff.html`, `word-diff.html`, `index.html`

## 背景・目的

現状の3つの差分ツールは、ファイルA・ファイルBの両方が読み込まれて初めて
内容の描画（比較結果の表示）が行われる作りになっている。片方のみ読み込んだ
状態では「シートを選ぶと差分が表示されます」等のプレースホルダのままで、
ファイルの中身を一切確認できない。

1ファイルだけ登録した場合でも、そのファイルの中身をそのまま閲覧できる
「ビュワーモード」として機能するようにする。2ファイル目を追加すれば、
現状通りの差分比較モードに自動的に切り替わる。

## 全体方針

- 3ツール共通の考え方で対応する。
  - `state.A` と `state.B` のどちらか一方だけが存在する状態でも、内容描画の
    処理を実行できるようにする（現状は両方揃うまで比較処理そのものが
    走らない）。
  - 表示には既存の比較テーブル／本文描画のレンダリング関数をそのまま流用する。
    相手ファイルが存在しないセル・行は全て「一致（same）」相当として扱い、
    差分色（追加=緑・削除=赤・変更=黄）を付けない通常表示にする。新規の
    専用ビューコンポーネントは作らない。
  - 比較専用のUI部品（サマリー件数、警告メッセージ、モード切替、キー選択など）
    は、1ファイルのみの時は非表示にする。
  - 2ファイル目を追加した瞬間、既存の差分比較ロジック・表示に自動的に
    切り替わる（既存動作は変更しない）。

## ツール別仕様

### Excel差分ビューア（excel-diff.html）

- **1ファイルのみ登録時**（A・Bどちらでも同様）:
  - タブには、そのファイルの**全シート名**を表示する（現状は「A・B双方に
    存在する同名シート」のみタブ化するロジックだが、1ファイルのみの場合は
    そのファイルの全シートを対象にする）。
  - 選択中シートの内容を既存のグリッド描画でそのまま表示する。結合セルは
    そのまま結合表示を再現し、差分色は付けない。
  - サマリー（一致/追加/削除/変更件数）・警告文・「比較するシートを選ぶ」
    チェックボックス（手動ペア選択UI）は非表示にする。
  - PDF出力ボタンは1ファイル表示中も有効のままとする（既存の印刷機能を
    流用）。
- **2ファイル目を追加した瞬間**: 現状通り、同名シートの自動ペアリングに
  よる差分比較に切り替わる。

### Accessビューア（access-diff.html）

- **1ファイルのみ登録時**（A・Bどちらでも同様）:
  - テーブル選択プルダウンには、そのファイルの**全テーブル名**を表示する
    （現状はA・B双方に存在する同名テーブルのみ）。
  - 選択中テーブルの全レコードを既存のグリッド描画でそのまま表示する
    （差分色なし）。
  - サマリー件数・警告文・「複合キー選択」ボタン（行の突き合わせ用UI）は
    非表示にする。複合キーによる行対応付けは差分専用の機能のため。
  - 列ヘッダクリックによるソート機能は1ファイルのみの場合も有効のままと
    する。
- **2ファイル目を追加した瞬間**: 現状通り、複合キーによる行対応付けを
  伴う差分比較に切り替わる。

### Word差分ビューア（word-diff.html）

- **1ファイルのみ登録時**（A・Bどちらでも同様）:
  - 本文をdiff処理なしのプレーンテキストとしてそのまま表示する（既存の
    「一致行」の見た目を流用）。
  - サマリー件数・表示モード切替（インライン/左右並列）・「差分行のみ
    折りたたみ」設定は非表示にする。
- **2ファイル目を追加した瞬間**: 現状通り、段落・語単位の差分比較に
  切り替わる。

## 文言更新

- `index.html` のサブタイトル（現状「Access・Excel・Word の2ファイルを
  ブラウザ内で比較（外部送信なし）」）を、1ファイルでもビュワーとして
  使える旨を含む文言に更新する。
- 各カードの説明文（例：「2つのDBの同名テーブルを、複合キーで行対応付け
  してセル単位に比較。…」）も、「1つならビュワー、2つなら比較」に触れる
  形に更新する。
- 各ツール画面上部のサブタイトル（例：excel-diff.htmlの「2つの .xlsx を
  シートごとにセル比較」）も同様に、1ファイルのみでも閲覧できる旨に更新
  する。

## テスト方針

- 手動確認（ブラウザで実ファイルを使用）:
  - Excel: ファイルAのみ登録し、複数シートを持つブックで各シートが
    タブ切り替えで通常表示されること。差分色が付かないこと。PDF出力が
    機能すること。その後ファイルBを追加し、既存の差分比較に自動で
    切り替わること。
  - Access: ファイルAのみ登録し、複数テーブルを持つDBでテーブル切替・
    ソートが機能すること。差分色が付かないこと。ファイルBを追加後に
    既存の差分比較へ切り替わること。
  - Word: ファイルAのみ登録し、本文がそのまま表示されること（差分ハイ
    ライトなし）。ファイルBを追加後に既存の差分比較へ切り替わること。
  - 逆にファイルBのみを先に登録した場合も同様に動作すること。
  - Cookie/localStorageによる設定復元（シート・テーブル選択、並び順等）
    が1ファイルのみの状態でも壊れないこと。
